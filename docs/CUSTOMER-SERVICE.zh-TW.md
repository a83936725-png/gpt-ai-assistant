# 客服模式（第 1 階段：內部測試）

開啟客服模式後，官方 LINE 的一對一聊天會變成客服：

- 客人傳的每一則文字（或語音）訊息都會直接回覆，不用下指令。
- **只根據 `knowledge/` 資料夾的內容回答**。沒寫到的問題不會亂編，而是回覆「已轉達專人」。
- 畫圖、搜尋等原本的指令在客服模式下都關閉，客人用不到。
- 群組裡不回覆。
- 傳圖片會請客人改用文字描述。

## 開啟步驟（Vercel → Settings → Environment Variables）

| 變數 | 設定值 | 說明 |
|---|---|---|
| `SERVICE_MODE_ENABLED` | `true` | 開啟客服模式 |
| `APP_ALLOWED_USER_IDS` | 測試同事的 ID，用逗號分隔 | **內部測試期間一定要設**，只有名單上的人會被回覆 |
| `BOT_NAME` | 你的品牌名稱 | 會放進客服的自我介紹 |

改完環境變數後要重新部署（Redeploy）才會生效。

### 怎麼拿到測試同事的 ID

1. 先把 `APP_ALLOWED_USER_IDS` 設成你自己的 ID（不知道的話先留空，部署後傳「我的ID」給官方帳號）。
2. 請同事加官方帳號好友，傳「我的ID」，把回覆的 ID 給你。
3. 加到 `APP_ALLOWED_USER_IDS`，重新部署。

客服模式開啟時，**不在名單上的人傳訊息，機器人完全不回**（傳「我的ID」除外），訊息照常留在官方帳號後台讓小編處理。所以可以直接在正式的官方帳號上做內部測試，客人不會收到機器人的回覆。

⚠️ `APP_ALLOWED_USER_IDS` 留空代表**所有人都會被機器人回覆**，正式開放前請不要清空。

## 可選設定

| 變數 | 預設 | 說明 |
|---|---|---|
| `SERVICE_FALLBACK_MESSAGE` | 「這個問題我需要請專人為您確認……」 | 答不出來時回覆客人的話 |
| `SERVICE_MAX_HISTORY_MESSAGES` | `6` | 記住最近幾則對話，讓客人可以追問（例如「那它多少錢？」） |
| `KNOWLEDGE_MAX_CHARS` | `30000` | 每次最多帶多少字的知識給 AI。知識庫比這個小時整份都會帶上；比較大時只帶最相關的段落 |

客人或測試同事傳「忘記」可以清掉對話紀錄，重新開始。

## 不用部署，在電腦上先測

```bash
npm install --omit=dev
npm run ask -- --file scripts/questions.txt
```

需要在 `.env` 設定 `OPENAI_API_KEY`、`BOT_NAME`。`npm run ask` 可以直接打字聊天。

## 答不出來的問題在哪裡看

第 1 階段先記在 Vercel 的 Logs（專案 → Logs），搜尋 `knowledge_miss`：

```
{"type":"knowledge_miss","userId":"U...","name":"客人暱稱","question":"你們有門市嗎？","at":"..."}
```

第 2 階段會改成存進資料庫，並直接推播通知你。

## 測試時建議問的問題

1. 知識庫裡明確寫了答案的問題 → 應該答對，數字要和知識庫一致。
2. 換個說法問同一件事（例如「運費」改成「寄送要錢嗎」）→ 應該還是答得出來。
3. 追問（先問某產品，再問「那它怎麼用？」）→ 應該知道「它」指的是哪個產品。
4. 知識庫沒有的事（例如「你們老闆是誰」）→ 應該回覆「已轉達專人」，**不能自己編答案**。
5. 打招呼、說謝謝 → 應該禮貌回應。
