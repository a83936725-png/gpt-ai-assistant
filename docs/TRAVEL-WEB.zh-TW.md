# 旅圖 eSIM 網頁版：操作彙整

出國旅遊 App 的網頁版，跟 LINE Bot、IKIGAI 放在同一個專案。部署到 Vercel 後打開：

- 網址：`https://<你的網域>/travel/`
- 本機：`npm run dev` 後開 `http://localhost:3000/travel/`（要先在 `.env` 設 `APP_PORT=3000`）

設計方向是「**旅遊雜誌 60% ＋ 專業產品介面 40%**」：首頁像一本旅遊雜誌，進到行程表後是真正能操作的 App。

---

## 一、資訊架構（5 個分頁）

| 分頁 | 用途 | 主要內容 |
| --- | --- | --- |
| 首頁 | 雜誌封面 | 下一趟旅行的大圖封面、Day 1～Day N 時間軸預覽、2025–2026 足跡摘要、世界地圖、下一站靈感 |
| 行程表 | 真正的操作介面 | 逐日時間軸（拖曳排序）、景點照片／影片／地圖／訂票、預算、待辦、景點庫 |
| 探索 | 附近的旅行推薦 | 依出發點、旅行元素、月份、飛行時間、門票預算篩選；旅遊卡翻面看景點與門票 |
| eSIM | 出國上網 | 我的 eSIM（使用中／待啟用／已到期）、依行程推薦方案、探索世界（地區＋國旗）、方案頁、購物車與結帳、分享給親友、圖文安裝教學 |
| 足跡 | 回顧與資料 | 2025／2026 年度回顧與徽章、旅遊卡圖片、行程清單、匯入 Google 地圖時間軸、備份、設定 |

## 二、功能重點

**一登入就知道去過哪裡**：首頁摘要寫出 2025、2026 各去了幾個國家、幾座城市、幾天、最常出現的旅行元素，地圖用顏色區分 2025（青綠）、2026（橘）、兩年都去（紫）、即將出發（虛線）。

**行程表（不用每次叫 AI 重新產生）**

- 拖曳左邊 ⋮⋮ 調整順序或移到別天，手機也能拖。也可以展開項目用「移到 Day X」。
- 點景點名稱：照片（Wikipedia）、📷 照片搜尋、▶️ YouTube 影片、🗺️ Google 地圖、🎟️ 訂票搜尋、官方觀光網，以及備註欄。
- 時間直接打數字，例如 `930` 會變成 `09:30`。
- 預算：機票、住宿、交通、餐飲、購物自己填；門票與 eSIM 會自動算進去，可設定人數與預算上限。
- 待辦：系統自動列出「買 eSIM／安裝 eSIM」、入境準備（例如 Visit Japan Web）、每個要門票的景點，也可以自己新增。
- 景點庫：還沒排進去的景點，加上 400 公里內可以順遊的城市，拖進任何一天即可。

**eSIM 購買與安裝流程**（參考 LINE 上的 eSIM 小程式操作，但用自己的設計）

1. 選國家 → 方案頁：每日定量（1／2／3GB，標示超量降速）、總量型（5／10／20GB）、吃到飽（標準／高速優先）。天數會依下一趟行程自動帶入，可以選張數幫家人一起買。
2. 不知道選哪個：「幫我挑方案」回答目的地、天數、用途、人數，直接推薦方案與張數。
3. 右下角購物車 → 結帳（示範，不扣款）→ 購買成功頁，可直接用 LINE 把其中一張分享給親友。
4. 我的 eSIM：每張卡有「取得 → 安裝 → 開通」三步驟，並依航線提醒安裝時機（短程：出發當天在機場安裝；長程：抵達後安裝）。
5. 安裝頁：安裝前檢查、**建議的手機標籤名稱**（目的地＋日期，例如「札幌旅遊 1218」，可複製）、iPhone 一鍵安裝、QR Code 區、「我已安裝完成」。
6. **防止重複安裝**：已安裝的卡再按安裝、同國家已有安裝中的卡、或要把「第 2 張」裝在自己手機時，都會先跳出提醒，建議改用「分享給親友」。
7. **圖文安裝教學**：iPhone／Android 逐步手機畫面（用你的標籤名稱標出要點的地方）、自動播放、抵達後的「設定總檢查表」、注意事項與連不上網的排除步驟。設定 `TRAVEL_GUIDE_VIDEO_URL` 會多一個「看影片教學」按鈕。
8. 親友收到 LINE 連結 → 打開頁面 →「親友送你網卡！」→ 確認領取 → 出現在他的「我的 eSIM」。

正式上線時要接的地方：付款、由伺服器產生一次性的領取連結、每張卡的安裝資料（LPA）。有 LPA 時，iPhone 一鍵安裝會直接用 Apple 的 `esimsetup.apple.com` 連結開啟系統的 eSIM 安裝畫面。

**照片**：每個目的地、景點、各國美食與文化都有實景照片（來自 Wikimedia Commons，標示作者與授權），以大圖相簿呈現。新增景點後執行 `node scripts/travel-photos.js` 重新產生 `web/travel-photos.json`。

**點國家看在地文化**：地圖上點任一國家，會出現必吃美食、必體驗文化（都有照片）、伴手禮、小提醒、推薦城市與 eSIM。

**探索世界（所有國旗）**：eSIM 分頁可依地區瀏覽全世界 200 多個國家；沒有單國方案的國家會自動對應「歐洲多國／亞洲多國／全球通用」。

**隨機出國**：設定每人預算、天數、月份與想要的元素，按「轉一下」抽出目的地，附上機票、住宿、門票、eSIM 的概估。

**預算回推**：行程表右側依目的地與天數概估總花費，設定預算上限後，會算出每人每天可以花多少（省錢／舒適／享受模式），並可「依預算自動調整景點」。探索頁也能用總預算篩選。

**回憶紀念冊**：2025、2026 各一本，封面拼貼、每趟一頁（實景照片、你自己上傳的照片、旅行日記），最後一頁是年度總結。照片只存在這台裝置。

**景點與門票**：每個目的地 3～5 個景點，標示「免費」或成人門票（當地幣別與約合新台幣），推薦卡顯示門票合計。

**旅遊卡**：足跡分頁按「🪪 旅遊卡」產生 1080×1350 的年度圖片，可下載或直接分享到 IG／Threads。

**匯入 Google 地圖時間軸**：支援手機匯出的 Timeline.json 與 Google Takeout 的位置記錄。檔案只在瀏覽器裡分析，不會上傳，會自動找出 2025、2026 的海外旅行。

## Threads 問答資料庫（@esim_87cc）

`data/esim-threads.json` 收錄 @esim_87cc 公開的回覆與貼文：提問、原文回覆、主題、標籤、連結，以及整理好的重點（`insight`）。比較同業的貼文標成 `internal`，不會放進 App。App 的 eSIM 常見問題前四題就是從這裡整理的（測速快但實際慢、日本選哪家、為什麼不追求最便宜、哪家最好）。

目前只收到未登入看得到的內容（4 則回覆、7 篇貼文）。留言串要登入才看得到，要收錄全部回覆：

1. Threads App → 設定 → 帳號 → 下載你的資訊（或 Meta 帳號管理中心 → 你的資訊和權限 → 下載你的資訊），選 Threads、格式選 JSON。
2. 收到檔案後解壓縮，執行 `node scripts/threads-import.js <解壓縮的資料夾>`，所有貼文與回覆會補進資料庫（會自動修正匯出檔的亂碼，已收錄的不會重複）。

## 三、環境變數（Vercel → Settings → Environment Variables）

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `TRAVEL_ENABLED` | `true` | 設成 `false` 會關閉 `/travel` |
| `TRAVEL_AI_ENABLED` | `true` | AI 行程建議（使用既有的 `OPENAI_API_KEY`）。關閉時顯示內建行程 |
| `TRAVEL_BRAND` | `旅圖 eSIM` | 頁面上的品牌名稱 |
| `TRAVEL_ESIM_URL` | `https://www.ccesim.com/` | 「到官網購買」的連結 |
| `TRAVEL_GUIDE_VIDEO_URL` | （空） | 安裝教學影片的網址（例如 YouTube），設定後圖文教學會多一個「看影片教學」按鈕 |
| `TRAVEL_MAX_TOKENS` | `1500` | AI 行程建議的長度上限 |
| `TRAVEL_TIMEOUT` | `50000` | AI 逾時（毫秒） |
| `TRAVEL_RATE_LIMIT` | `10` | 每個 IP 每小時可以要幾次 AI 行程 |

## 四、目前是示範版的地方（上線前要換）

- **登入與資料**：帳號、行程、預算都存在瀏覽器 localStorage，換手機就看不到。正式版要接 Google／LINE 登入與資料庫。
- **eSIM 價格、方案與期限**：`web/travel-data.js` 裡的 `base`、`PACKS`、`PLAN_TYPES`（降速、說明）、`POLICY`（領取／安裝／開通期限）都是示意，請換成官網實際內容；結帳不會扣款，正式購買連到 `TRAVEL_ESIM_URL`。
- **分享給親友**：示範版的連結只帶方案資訊（不是真的 eSIM），正式版要由伺服器產生一次性領取連結。
- **門票價格**：2026 年參考價，匯率是概估，請定期對照景點官網。
- **eSIM 常見問題**：是一般 eSIM 的規則，請依官網條款修改 `web/travel-app.js` 的 `FAQ`。
