# 旅圖 eSIM 網頁版：操作彙整

出國旅遊 App 的網頁版，跟 LINE Bot、IKIGAI 放在同一個專案。部署到 Vercel 後打開：

- 網址：`https://<你的網域>/travel/`
- 本機：`npm run dev` 後開 `http://localhost:3000/travel/`（要先在 `.env` 設 `APP_PORT=3000`）

設計方向是「**旅遊雜誌 60% ＋ 專業產品介面 40%**」：首頁像一本旅遊雜誌，進到行程表後是真正能操作的 App。

---

## 一、資訊架構（5 個分頁）

| 分頁 | 用途 | 主要內容 |
| --- | --- | --- |
| 首頁 | 雜誌封面 | 下一趟旅行的大圖封面、Day 1～Day N 時間軸預覽、2025–2026 足跡摘要、世界地圖、下一站靈感 |
| 行程表 | 真正的操作介面 | 逐日時間軸（拖曳排序）、景點照片／影片／地圖／訂票、預算、待辦、景點庫 |
| 探索 | 附近的旅行推薦 | 依出發點、旅行元素、月份、飛行時間、門票預算篩選；旅遊卡翻面看景點與門票 |
| eSIM | 出國上網 | 我的 eSIM（使用中／待啟用／已到期）、依行程推薦方案、探索世界（地區＋國旗）、方案頁、購物車與結帳、分享給親友、圖文安裝教學 |
| 足跡 | 回顧與資料 | 2025／2026 年度回顧與徽章、旅遊卡圖片、行程清單、匯入 Google 地圖時間軸、備份、設定 |

## 二、功能重點

**一登入就知道去過哪裡**：首頁摘要寫出 2025、2026 各去了幾個國家、幾座城市、幾天、最常出現的旅行元素，地圖用顏色區分 2025（青綠）、2026（橘）、兩年都去（紫）、即將出發（虛線）。

**擬真世界地圖**：左上角切換「3D 地球／平面地圖」（會記住選擇）。

- 3D 地球：NASA Blue Marble 衛星影像貼在地球上（WebGL），手指拖曳旋轉、甩一下會繼續轉、雙指或滾輪縮放，外圈有大氣層光暈。手機不支援 WebGL 時改畫成一般地球，照樣能用。
- 平面地圖：同一張衛星影像（麥卡托投影，和 Google 地圖一樣的形狀）。
- 中文國名：放得下才顯示，越放大越多；去過的國家會在名字前加國旗。也有海洋名稱。
- 照片圖釘：每趟旅行一個圓形實景照片，右下角是國旗，顏色代表年份；太近的會合併成一個並顯示趟數，點一下自動放大。放大到一個區域後，會出現還沒去過的推薦景點照片，點了看景點、門票、飛行時間，可以直接排行程或買 eSIM。
- 景點照片圖層：3D 地球與平面地圖上直接放各國必去景點的小照片圖釘，每國最有名的一個先出現，放大後顯示更多，圖釘不會互相重疊；轉動地球就會看到其他國家的景點照片。點照片打開景點介紹。地圖右上角的照片按鈕可以關掉這一層。
- 地球閒置幾秒會自己慢慢轉，讓不同國家的景點照片輪流出現；每隔幾秒在正面某張照片上「跳出」推薦泡泡（景點、國家、飛行時間），點泡泡就打開那個景點。一碰地圖、選了國家、全螢幕、地圖捲出畫面或手機開了「減少動態效果」就會停。
- 搜尋：地圖左上角的放大鏡可以找國家（中文或英文名稱）與景點，例如「富士山」「peru」；選了就飛過去、框出國家並標出景點。
- 點地圖上任何國家：地球會轉過去並框出這個國家，它的必去景點一個個以照片圖釘「跳」出來，下方滑出景點卡（手機在地圖下面，電腦與全螢幕浮在地圖上）。點景點看大圖、介紹、Google 地圖、維基百科、「在 3D 地圖上看」與同國家的其他推薦；「美食・文化・城市」打開國家頁（在地美食與文化、國旗、飛行時間）。第一次進來時地圖上會浮出「點一個國家，看必去景點」的提示。
- 操作方式：手機上單指在地圖上滑動是捲動頁面（不會卡住），兩指轉動與縮放地圖；橫向滑動時會提示。電腦上滾輪是捲動頁面，按住 Ctrl（Mac 用 ⌘）再滾動、或觸控板雙指縮放才會縮放地圖。右上角 ⤢ 開全螢幕地圖，全螢幕裡單指就能轉地球、拖地圖，按 ✕ 或 Esc 關閉。

**飛行時間**：每個國家（探索世界的國旗卡、國家頁、行程、旅遊卡、徽章）都會寫「直飛約 X 小時」或「轉機約 X 小時」。台灣有直飛的航線用直飛時間（有收錄的城市用該城市的時間），其他國家以一次轉機、約 2.5 小時轉機時間估算，並附距離。都是概估，實際以航班為準。出發城市在「足跡 → 備份與設定」切換（台北／台中／高雄）。探索世界可以按「由近到遠」，依飛行時間排序全部 203 個國家與地區。

**旅遊卡**：足跡分頁最上面，每趟旅行一張收藏卡（實景照片、國旗、編號、季節、天數、飛行時間、年份郵戳）。點一下翻面，背面像登機證：出發地 → 目的地、日期、距離、eSIM 用量、吃了什麼、做了什麼、旅行日記。可以「下載卡片」（1080×1350）或直接分享。

**徽章（30 個）**：分成里程碑、旅行元素、旅行方式三組，足跡分頁有「徽章牆」，年度回顧也會顯示最接近解鎖的幾個。點任何徽章都能看「你做了什麼、吃了什麼」：

- 美食獵人、文化探索家：每趟旅行列出當地必吃美食／必體驗文化的照片，點一下標記「吃過了／做過了」，沒列出來的可以自己輸入（例如「一蘭拉麵」）。打卡 10 道會解鎖「吃貨認證」。
- 其他元素徽章：列出符合的旅行與行程裡去過的景點。
- 五國旅人、十國收藏家、亞洲通、歐洲漫遊者：收集到的國旗。跨洲旅人：每一洲去過哪些國家。萬里旅人、繞地球一圈：每趟的航線與公里數。四季旅人：春夏秋冬各去了哪裡。
- 已解鎖的會寫達成日期；還沒解鎖的顯示進度，並推薦可以解鎖它的目的地。
- 旅行的「吃了什麼・做了什麼」也可以在行程詳情裡打卡，會跟著 LINE 登入同步。

**行程表（不用每次叫 AI 重新產生）**

- 拖曳左邊 ⋮⋮ 調整順序或移到別天，手機也能拖。也可以展開項目用「移到 Day X」。
- 點景點名稱：照片（Wikipedia）、📷 照片搜尋、▶️ YouTube 影片、🗺️ Google 地圖、🎟️ 訂票搜尋、官方觀光網，以及備註欄。
- 時間直接打數字，例如 `930` 會變成 `09:30`。
- 預算：機票、住宿、交通、餐飲、購物自己填；門票與 eSIM 會自動算進去，可設定人數與預算上限。
- 待辦：系統自動列出「買 eSIM／安裝 eSIM」、入境準備（例如 Visit Japan Web）、每個要門票的景點，也可以自己新增。
- 景點庫：還沒排進去的景點，加上 400 公里內可以順遊的城市，拖進任何一天即可。

**eSIM 購買與安裝流程**（參考 LINE 上的 eSIM 小程式操作，但用自己的設計）

1. 選國家 → 方案頁：每日定量（1／2／3GB，標示超量降速）、總量型（5／10／20GB）、吃到飽（標準／高速優先）。天數會依下一趟行程自動帶入，可以選張數幫家人一起買。
2. 不知道選哪個：「幫我挑方案」回答目的地、天數、用途、人數，直接推薦方案與張數。
3. 右下角購物車 → 結帳（示範，不扣款）→ 購買成功頁，可直接用 LINE 把其中一張分享給親友。
4. 我的 eSIM：每張卡有「取得 → 安裝 → 開通」三步驟，並依航線提醒安裝時機（短程：出發當天在機場安裝；長程：抵達後安裝）。
5. 安裝頁：安裝前檢查、**建議的手機標籤名稱**（目的地＋日期，例如「札幌旅遊 1218」，可複製）、iPhone 一鍵安裝、QR Code 區、「我已安裝完成」。
6. **防止重複安裝**：已安裝的卡再按安裝、同國家已有安裝中的卡、或要把「第 2 張」裝在自己手機時，都會先跳出提醒，建議改用「分享給親友」。
7. **圖文安裝教學**：iPhone／Android 逐步手機畫面（用你的標籤名稱標出要點的地方）、自動播放、抵達後的「設定總檢查表」、注意事項與連不上網的排除步驟。設定 `TRAVEL_GUIDE_VIDEO_URL` 會多一個「看影片教學」按鈕。
8. 親友收到 LINE 連結 → 打開頁面 →「親友送你網卡！」→ 確認領取 → 出現在他的「我的 eSIM」。

正式上線時要接的地方：付款、由伺服器產生一次性的領取連結、每張卡的安裝資料（LPA）。有 LPA 時，iPhone 一鍵安裝會直接用 Apple 的 `esimsetup.apple.com` 連結開啟系統的 eSIM 安裝畫面。

**照片**：每個目的地、景點、各國美食與文化都有實景照片（來自 Wikimedia Commons，標示作者與授權），以大圖相簿呈現。新增景點後執行 `node scripts/travel-photos.js` 重新產生 `web/travel-photos.json`。

**點國家看在地文化**：地圖上點任一國家，會出現必吃美食、必體驗文化（都有照片）、伴手禮、小提醒、推薦城市與 eSIM。

**探索世界（所有國旗）**：eSIM 分頁可依地區瀏覽全世界 200 多個國家，每個都有國旗圖片與飛行時間；沒有單國方案的國家會自動對應「歐洲多國／亞洲多國／全球通用」。國旗用圖片而不是 emoji，因為 Windows 電腦會把 emoji 國旗顯示成兩個英文字母。

**隨機出國**：設定每人預算、天數、月份與想要的元素，按「轉一下」抽出目的地，附上機票、住宿、門票、eSIM 的概估。

**預算回推**：行程表右側依目的地與天數概估總花費，設定預算上限後，會算出每人每天可以花多少（省錢／舒適／享受模式），並可「依預算自動調整景點」。探索頁也能用總預算篩選。

**回憶紀念冊**：2025、2026 各一本，封面拼貼、每趟一頁（實景照片、你自己上傳的照片、旅行日記），最後一頁是年度總結。照片只存在這台裝置。

**紀念冊匯出與分享**：紀念冊下方可以「存這一頁」「全部存成圖片」（每頁 1080×1350，適合 IG／Threads）、「分享圖片」（手機直接分享到 LINE、IG 或存到相簿）、「分享連結」（朋友不用登入就能翻閱，含目的地照片、日期與旅行日記；你自己上傳的照片只存在手機，不會放進連結）、「列印／存成 PDF」。

**景點與門票**：每個目的地 3～5 個景點，標示「免費」或成人門票（當地幣別與約合新台幣），推薦卡顯示門票合計。

**年度分享圖**：足跡分頁按「年度分享圖」產生 1080×1350 的年度圖片（含去過國家的國旗），可下載或直接分享到 IG／Threads。

**匯入 Google 地圖時間軸**：支援手機匯出的 Timeline.json 與 Google Takeout 的位置記錄。檔案只在瀏覽器裡分析，不會上傳，會自動找出 2025、2026 的海外旅行。

## Threads 問答資料庫（@esim_87cc）

`data/esim-threads.json` 收錄 @esim_87cc 公開的回覆與貼文：提問、原文回覆、主題、標籤、連結，以及整理好的重點（`insight`）。比較同業的貼文標成 `internal`，不會放進 App。App 的 eSIM 常見問題前四題就是從這裡整理的（測速快但實際慢、日本選哪家、為什麼不追求最便宜、哪家最好）。

目前只收到未登入看得到的內容（4 則回覆、7 篇貼文）。留言串要登入才看得到，要收錄全部回覆：

1. Threads App → 設定 → 帳號 → 下載你的資訊（或 Meta 帳號管理中心 → 你的資訊和權限 → 下載你的資訊），選 Threads、格式選 JSON。
2. 收到檔案後解壓縮，執行 `node scripts/threads-import.js <解壓縮的資料夾>`，所有貼文與回覆會補進資料庫（會自動修正匯出檔的亂碼，已收錄的不會重複）。

## LINE 登入與雲端同步

設定好之後，登入頁會出現「用 LINE 登入（資料雲端同步）」；在 LINE 裡打開網址會自動登入。行程、行程表、預算、eSIM 訂單與設定都存在你的 Vercel Blob，換手機登入同一個 LINE 帳號就看得到。紀念冊裡自己上傳的照片太大，仍只存在手機。

設定步驟：

1. [LINE Developers](https://developers.line.biz/console/) → 選擇 LINE Bot 所在的 Provider → **Create a new channel** → **LINE Login**（App types 勾 Web app）。
2. 進入這個 LINE Login channel → **LIFF** 分頁 → **Add**：
   - Size：Full
   - Endpoint URL：`https://<你的網域>/travel/`
   - Scopes：勾選 `openid`、`profile`
   - 加好友選項（Add friend option）：可選 On (normal)，讓使用者順便加官方帳號好友
3. 複製 LIFF ID（格式像 `1234567890-AbCdEfGh`），在 Vercel 加環境變數 `TRAVEL_LIFF_ID`。
4. 儲存空間：沿用 IKIGAI 的 Vercel Blob（`IKIGAI_BLOB_READ_WRITE_TOKEN`）即可；想分開就建立新的 Blob store，把 token 填進 `TRAVEL_BLOB_READ_WRITE_TOKEN`。
5. Redeploy。用 `https://liff.line.me/<LIFF ID>` 這個網址分享，在 LINE 裡打開會直接登入。

伺服器會向 LINE 驗證每次同步帶來的登入憑證（ID token），每個 LINE 帳號只能讀寫自己的資料。

## 三、環境變數（Vercel → Settings → Environment Variables）

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `TRAVEL_ENABLED` | `true` | 設成 `false` 會關閉 `/travel` |
| `TRAVEL_AI_ENABLED` | `true` | AI 行程建議（使用既有的 `OPENAI_API_KEY`）。關閉時顯示內建行程 |
| `TRAVEL_BRAND` | `旅圖 eSIM` | 頁面上的品牌名稱 |
| `TRAVEL_ESIM_URL` | `https://www.ccesim.com/` | 「到官網購買」的連結 |
| `TRAVEL_LIFF_ID` | （空） | LINE Login channel 的 LIFF ID，設定後開啟 LINE 登入與雲端同步 |
| `TRAVEL_BLOB_READ_WRITE_TOKEN` | （沿用 IKIGAI 或 `BLOB_READ_WRITE_TOKEN`） | 存放同步資料的 Vercel Blob token |
| `TRAVEL_LINE_CHANNEL_ID` | （LIFF ID 前半段） | 通常不用設；LINE Login channel ID 與 LIFF ID 不同時才需要 |
| `TRAVEL_GUIDE_VIDEO_URL` | （空） | 安裝教學影片的網址（例如 YouTube），設定後圖文教學會多一個「看影片教學」按鈕 |
| `TRAVEL_MAX_TOKENS` | `1500` | AI 行程建議的長度上限 |
| `TRAVEL_TIMEOUT` | `50000` | AI 逾時（毫秒） |
| `TRAVEL_RATE_LIMIT` | `10` | 每個 IP 每小時可以要幾次 AI 行程 |

## 四、目前是示範版的地方（上線前要換）

- **登入與資料**：設定 `TRAVEL_LIFF_ID` 後可用 LINE 登入並雲端同步；沒設定時，資料只存在瀏覽器。
- **eSIM 價格、方案與期限**：`web/travel-data.js` 裡的 `base`、`PACKS`、`PLAN_TYPES`（降速、說明）、`POLICY`（領取／安裝／開通期限）都是示意，請換成官網實際內容；結帳不會扣款，正式購買連到 `TRAVEL_ESIM_URL`。
- **分享給親友**：示範版的連結只帶方案資訊（不是真的 eSIM），正式版要由伺服器產生一次性領取連結。
- **門票價格**：2026 年參考價，匯率是概估，請定期對照景點官網。
- **eSIM 常見問題**：是一般 eSIM 的規則，請依官網條款修改 `web/travel-app.js` 的 `FAQ`。

## 五、修改資料

- 國家、目的地、景點門票、eSIM 方案：`web/travel-data.js`
- 畫面與樣式：`web/travel.html`
- 互動邏輯：`web/travel-app.js`
- 地圖（3D 地球、平面衛星圖、國名、圖釘）：`web/travel-map.js`
- 國名位置與航班落地城市：`web/travel-geo.js`，由 `node scripts/travel-geo.js <world-countries 的 countries.json>` 產生；大國的落地城市（例如美國用洛杉磯）寫在腳本的 `HUBS`
- 衛星影像：`web/travel-earth/`，由 `python3 scripts/travel-earth.py <earth-blue-marble.jpg>` 產生（2048／4096 寬，地球用等距圓柱、平面用麥卡托）
- 直飛航線清單與轉機時間：`web/travel-app.js` 的 `DIRECT` 與 `flightInfo`
- 各國必去景點：`scripts/travel-sights-list.js`（中文名稱、英文維基百科條目、一句話介紹），執行 `node scripts/travel-sights.js` 抓照片、作者授權與座標，產生 `web/travel-sights.json`。被 Wikipedia 限流時會把結果存在 `.travel-sights-cache.json`，再執行一次會接著抓；沒抓到的景點，訪客的瀏覽器會自己向 Wikipedia 要照片與位置。
