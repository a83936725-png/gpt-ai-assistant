# 客服知識庫

這個資料夾裡的每一個 `.md` 檔都會被客服機器人讀取，用來回答客人的問題。
機器人**只會根據這裡寫的內容回答**；這裡沒寫的事，它會回覆客人「已轉達專人」。

## 怎麼寫

- 一個主題（例如一項產品、運送方式、退換貨）一個檔案，檔名用中文或英文都可以，例如 `產品-保濕精華.md`、`運送與付款.md`。
- 第一行用 `# ` 寫標題。
- 每個小主題用 `## ` 開頭。機器人會以 `## ` 為單位搜尋，所以**同一件事放在同一個 `##` 底下**，不要拆散。
- 價格、規格、時間寫清楚具體數字，機器人不會自己補。
- 也可以直接寫成「問：……／答：……」的形式。

可以參考 `_範本.md`。

## 不會被讀取的檔案

- 檔名以 `_` 或 `.` 開頭的檔案（例如 `_範本.md`），適合放草稿或範本。
- `README.md`（就是這份說明）。

## 更新之後

改完檔案、推到 GitHub 後，Vercel 會重新部署，機器人就會讀到新內容。

## ⚠️ 注意

這裡的內容客人都有可能問得到。**內部資料（成本、進貨價、內部流程、員工個資）不要放進來。**
