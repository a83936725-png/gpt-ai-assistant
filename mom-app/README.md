# 易家做媽媽（Mom App）

易家滴雞精陪你從 **備孕、懷孕到育兒** 的網頁 App（PWA）。

- 🏝️ **好孕島**：可以逛的衛教小島（集章、小測驗、日夜四季）
- 🍼 **育兒紀錄**：親餵左右計時、瓶餵、擠奶、尿布（便便顏色）、睡眠、體溫、副食品
- ✨ **接下來**：預測下一餐、睡意時間窗、換尿布
- 🧊 **母乳庫存**：冷藏／冷凍到期提醒、先到期先用
- 📈 **健康**：WHO 成長曲線、疫苗時程、兒童健檢、發展里程碑、統計圖表、PDF 照護報告
- 🌱 **備孕**：經期日曆、排卵預測、葉酸打卡、孕前清單
- 🤰 **懷孕**：孕週＆寶寶大小、產檢時程與紀錄、身體狀況日記、胎動計數、宮縮計時、孕期體重、待產包
- 🗺️ **孕產路線圖**：懷孕 → 生產 → 坐月子，每階段該做的事＋注意事項，記到警訊立刻提醒就醫
- 🍲 **坐月子**：生產紀錄、產後恢復紀錄（惡露、傷口、心情）、新生兒前 4 週觀察
- 💜 **品牌**：每日「滴雞精時光」打卡、提醒、官網／LINE 導流
- 👨‍👩‍👧 **家人共用紀錄**：爸爸、阿嬤的手機一起記錄，端對端加密同步（伺服器只存看不懂的密文，金鑰只在邀請連結裡）；也可以備份合併
- 📸 **寶寶月照**：出生、滿月到 2 歲每個月一張，四種相框、拖曳縮放、身高體重和一句話，存成 1080×1350 圖片或分享；12 個月做成「第一年」拼貼；照片只存在手機
- 🎬 **成長回顧**：滿月、百日、第一年、到今天，把手機裡的紀錄做成一段故事（喝了幾次奶、陪了幾個深夜、換了幾片尿布、長大多少、每一個第一次），可存成分享卡；在手機上做，不上傳
- 🤝 **交接卡**：換人顧寶寶時一張卡講清楚（上一餐、下一餐大約、尿布、睡眠、計時中、母乳庫存、交代事項）；傳到 LINE 的文字不放用藥和體溫；開了家人共用，按一下就通知家人「換你顧寶寶囉」
- 🌙 **夜奶陪伴**：深夜開始餵奶時換成暗暗暖暖的陪伴畫面：大字計時、左右換邊、每二十秒一句輕輕的話、螢幕保持亮著；有會員服務時顯示真實的「還有幾位媽媽也醒著」，可以和島上的媽媽揮手
- 📲 **手機通知**：App 關著也收得到團購進度、餵奶／預約／滴雞精提醒、家人消息（提醒只把種類和時間交給伺服器）；LINE 會員可改用官方帳號通知
- 📊 **品牌數據後台**（`#/admin`，給品牌端）：會員、每日註冊與開啟、今天／本週／本月在用的手機、新使用者的階段、記錄了什麼、滴雞精打卡、品牌頁到官網、分享管道、同週好孕圈的預產月份與寶寶月齡、邀請、團購成團率、功能使用，只有次數沒有是誰，可匯出 CSV
- ⚡ **快速操作**：一鍵記錄＋復原、自訂首頁快速鍵、長按 App 圖示捷徑、夜間模式（跟著各地日出日落）、二寶模式、月曆、傳給家人
- 📹 **看寶寶**：舊手機當攝影機，同一個 Wi-Fi 點對點、不經伺服器
- 🎒 **外出好幫手**：依寶寶紀錄估算外出包、週末計畫、找活動與哺乳室
- 🛍️ **常見好物**：依階段與寶寶月齡推薦要準備的東西、怎麼挑、安全提醒、哪些先別買；我的清單（要買／已有／價格加總）、願望清單分享給親友
- 🔎 **問答搜尋**：常見育兒問答＋全 App 內容搜尋
- 📤 **分享與邀請**：LINE／IG／FB／Threads 分享卡、邀請碼、好孕點數、關鍵時刻提醒
- 🛒 **團購揪團**：品牌設定的團購，媽媽開一團、把連結傳到群組，湊滿人數就成團，每個人拿到折扣碼到官網結帳（App 不收款、不收地址）
- 💰 **補助福利**：25 項補助、假別與手續（生育 10 萬、育兒津貼、托育補助、育嬰留停 8 成薪、哺乳時間、報稅扣除額…），寫清楚金額、什麼時候辦、官方連結；首頁依寶寶天數提醒「現在可以申請的福利」，有期限的會倒數
- 🎁 **雙向邀請禮**：朋友用你的連結或邀請碼加入、完成設定並註冊會員，朋友拿 30 點見面禮、你每位拿 50 點邀請禮；邀請的人只看得到人數
- 👥 **會員**：Email／手機／LINE 登入、即時在線與註冊人數、成功邀請人數；註冊要勾選同意隱私權政策（依個資法第 8 條告知），設定寄送服務後 Email／手機註冊要輸入驗證碼、可以用驗證碼重設忘記的密碼；可下載我的會員資料、修改暱稱、關閉行銷訊息、刪除帳號
- 👭 **島上的媽媽**：自己選擇加入後，在好孕群島看到同階段媽媽的 Q 版角色，互相 👋 揮手、💜 送愛心（只有固定四種互動，不能私訊；可封鎖、檢舉）
- 🗳️ **同週好孕圈**：和同一週預產（或同月出生寶寶）的媽媽每週回答一題小問題、分享心情、互相加油；匿名，3 位以上回答才公布結果
- 📮 **家族週報**：每週日把寶寶這週的喝奶、睡眠、新技能、身高體重（懷孕時是孕週與寶寶的變化）做成一張卡，一鍵傳到家族 LINE 群組；可加一句給家人的話，不放醫療紀錄
- 💌 **祝福牆**：滿月、百日、週歲（懷孕時是好孕加油牆），親友不用下載 App 就能留言，媽媽確認後才公開，可存成祝福卡

完整拆解、功能對照、法規注意事項與部署方式請看 [docs/TEARDOWN.md](docs/TEARDOWN.md)；孕期到出生的逐步操作截圖請看 [docs/FLOW.md](docs/FLOW.md)。

## 介紹頁（試閱本）

`lp/` 是雜誌風的介紹頁：封面、本期目錄、「一位媽媽的 24 小時」、六種會動的卡片（編號裝置展示、抽象賣點卡、弧形扇卡、立體環視卡、精選畫廊卡、彩虹扇卡），讀到 03:12 整頁會變成夜晚；最後是可以直接操作的 App 試玩（`index.html?sandbox=1`：獨立的儲存空間和範例資料，不會動到自己的紀錄），五個試玩任務做完會自己打勾。做法、提示詞關鍵字與五個階段的修改紀錄在 [docs/LANDING-CARDS.md](docs/LANDING-CARDS.md)。

## 快速開始

```bash
# 只看 App（不含登入與人數）
cd mom-app && python3 -m http.server 8080
# 打開 http://localhost:8080 ，選「先看看範例資料」
```

```bash
# 完整版（App＋會員 API），在 repo 根目錄執行
APP_PORT=8080 node api/index.js
# 打開 http://localhost:8080/mom-app/
```

部署與會員功能設定請看 [docs/GROWTH.md](docs/GROWTH.md) 第五節；四個參考來源的交叉比對在 [docs/COMPARE.md](docs/COMPARE.md)。

品牌名稱、LOGO、官網與 LINE 連結都在 [`config.js`](config.js) 設定。
