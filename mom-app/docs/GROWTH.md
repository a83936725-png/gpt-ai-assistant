## 二、品牌端要做的（App 外）

1. **IG 留言送連結**（參考 Reel 的 2,909 則留言）：品牌 IG 發「留言 +1 送你孕週卡／外出包清單」，用 Meta 官方自動私訊或合作工具回覆**帶邀請碼的連結**（`utm_source=instagram&utm_campaign=ig-comment`）。
2. **LINE 官方帳號關鍵字回覆**：「做媽媽」「孕週」「外出包」→ 回 App 連結（網址後面加 `?openExternalBrowser=1`，例如 `https://ikigai-tw.vercel.app/mom-app/?openExternalBrowser=1`，在 LINE 點開才會用手機的瀏覽器打開）；把 `config.js` 的 `lineOaUrl` 填好，App 內「LINE 諮詢」鈕會導到官方帳號。
3. **門市／產後護理之家**：桌卡放 App QR（用邀請頁的 QR，或 `utm_source=store`）。很多人用 LINE 掃 QR，網址一樣加 `openExternalBrowser=1`。
4. **KOL／醫師合作**：每位合作對象一個專屬邀請碼，邀請頁的「成功邀請人數」就是成效。
5. **獎勵兌現**：好孕點數 100 點顯示的優惠碼，到官網結帳使用；若要防止重複使用，建議用一次性序號（第二階段：由後端依帳號發放）。

## 四、隱私與法規

- **個資法**：註冊前一定要勾選同意《隱私權政策與使用條款》（App 內有完整的第 8 條告知事項），同意的版本與時間存在帳號裡；行銷訊息另外勾選、可隨時免費關閉；會員可以下載自己的資料、修改暱稱、刪除帳號。上線前請完成 `config.js` 的 `privacy` 欄位並請法務審閱（清單見 TEARDOWN「個資檢查與勾選同意」）。

- 分享卡**預設不放寶寶照片**，寶寶名字可隱藏；**醫療紀錄（看診、用藥、體溫、產後狀況）不做成公開分享卡**。
- 邀請連結只帶邀請碼與暱稱（可在分享面板關掉名字）。
- 「島上的媽媽」預設不開；加入後只分享畫的 Q 版角色、所在的島、自己取的名稱，不分享照片、週數、寶寶資料與紀錄；陌生人之間只有固定四種互動，沒有私訊與留言。
- 「同週好孕圈」預設不加入；只送出預產期是哪一週（不是日期）或寶寶出生年月，以及匿名的回答；結果只顯示總數，3 位以上回答才公布。
- 祝福牆的祝福要媽媽按「顯示」才公開；名稱與祝福裡的電話、連結、Email、LINE ID 會被伺服器拿掉。
- 品牌文案依食品安全衛生管理法第 28 條，不宣稱療效。
- 點數獎勵若改成抽獎或高額贈品，請先確認公平交易與贈品相關規範。
- **團購揪團**：
  - 團購的品名與說明同樣依食品安全衛生管理法第 28 條，不能誇大，也不能宣稱醫療效能。
  - 「原價」要是真的賣過的價格。人數由伺服器計算，是真實的會員人數，不能灌人數或灌原價：公平交易法第 21 條規定，價格、數量等足以影響交易決定的事項，不得有虛偽不實或引人錯誤的表示（[條文](https://law.lia-roc.org.tw/Law/Content?bp=3&lsid=FL011898)）。
  - 第一階段在品牌官網結帳。網路購物一般有 7 天解除權（消費者保護法第 19 條）；易於腐敗、保存期限較短的商品，可依「通訊交易解除權合理例外情事適用準則」排除，但必須事先告知消費者（[準則](https://6laws.net/6law/law3/通訊交易解除權合理例外情事適用準則.htm)）。滴雞精適不適用，請依實際保存條件確認，並寫在官網的商品頁與結帳頁。
  - 第二階段若改在 App 裡結帳、收地址，要另外告知並取得同意。

## 五、開啟會員功能（登入、人數、邀請計數）

會員 API 跟著這個 repo 的伺服器一起部署（`mom-api/`，掛在 `/mom-app/api`）。在 Vercel 專案的 Environment Variables 設定：

| 變數 | 必填 | 說明 |
|---|---|---|
| `MOM_AUTH_SECRET` | ✅ | 至少 32 字的隨機字串（用來簽登入憑證），例如 `openssl rand -hex 32`；少於 32 字在任何環境都不會被使用；正式環境沒設定時，登入會自動關閉（人數照常顯示） |
| `KV_REST_API_URL`、`KV_REST_API_TOKEN` | ✅ | 在 Vercel 加入 KV／Upstash Redis 整合後自動產生（沒設定時用記憶體，人數會標「測試環境」且重啟就歸零） |
| `LINE_LOGIN_CHANNEL_ID`、`LINE_LOGIN_CHANNEL_SECRET` | 選填 | 在 LINE Developers 建立 LINE Login channel；Callback URL 填 `https://你的網域/mom-app/api/auth/line/callback`，填好後登入頁才會出現「用 LINE 登入」 |
| `MOM_PUBLIC_URL` | 用 LINE 登入時必填 | App 的正式網址（例如 `https://你的網域/mom-app/`），LINE 登入完成後導回這裡；正式環境沒填時 LINE 登入會關閉（不讓網址由請求的 Host 決定） |
| `MOM_TRUST_PROXY` | 視部署 | 伺服器前面有幾層代理（nginx、負載平衡器）就填幾，例如 `1`，次數限制才會以每位使用者計算；直接對外或在 Vercel 上請不要填 |
| `MOM_ALLOWED_ORIGINS` | 選填 | 如果 App 放在別的網域，填那個網域（逗號分隔）讓它能呼叫 API |
| `MOM_GROUPBUYS` | 選填 | 團購揪團的團購設定（JSON 陣列，見下方）；沒設定就不顯示團購 |
| `MOM_GROUPBUY_DEMO` | 測試用 | 設成 `1` 會多一個標「測試環境」的示範團購（3 人成團、折扣碼 DEMO-0000），正式環境不要設 |

`MOM_GROUPBUYS` 範例（折扣碼只在伺服器，成團前不會送到任何手機）：

```json
[{"id":"gb-2026-12","title":"易家滴雞精 10 入","desc":"常溫保存","emoji":"🍲","image":"https://…/product.jpg",
  "price":1980,"listPrice":2400,"size":5,"hours":72,"starts":"2026-12-01","ends":"2026-12-31",
  "shopUrl":"https://你的官網/團購頁","code":"YIJIA-TEAM","codeNote":"結帳時輸入，每位會員限用一次"}]
```

`id` 用小寫英數與 `-`；`size` 幾人成團（2–20）；`hours` 開團後幾小時內要湊齊（最多 14 天，而且不會超過活動結束，台灣時間）；`listPrice` 是真的賣過的原價（選填，要比團購價高才會顯示）；`code` 請在官網後台設定使用次數（例如每位會員一次）。

限時團購：`starts`／`ends` 可以只寫日期（`"2026-12-31"`，到那天 24:00 結束），也可以寫到幾點幾分（`"2026-12-31T20:00"`，台灣時間）。App 的好孕島左側會有一排團購小圖，每秒倒數；團購頁「正在開團」每個團購都有大倒數。開過幾團、幾位媽媽參加、幾團成團是伺服器算的真實總數（不含任何人的資料），參加人數達到 `config.js` 的 `groupbuyStatsFrom`（預設 3 人）才顯示。

即時團購：開團時可以勾「公開這一團」（預設勾，`config.js` 的 `groupbuyPublicDefault` 可改成 `false`）。公開的團會出現在團購頁每個團購下面的「正在揪的團」，其他會員可以直接按「跟團」；最接近成團的排最前面，只差 1 人時標紅色「差 1 人」，好孕島的小圖也會寫「差1人」。團購頁上方有一行「即時」動態（誰開了一團、有人跟團、成團了，最近 24 小時）。App 停在團購頁或好孕島時每 15 秒更新一次（`GET /groupbuy/live`）。只顯示團名、人數和剩下的時間；開團的人可以在團的頁面隨時取消公開，取消公開或刪除帳號時，團名會立即從清單和動態移除。

網頁預覽版（沒有會員伺服器）一打開就會出現三個標「範例」的團購（`config.js` 的 `groupbuyPreview: true`；載入「範例資料」時也會），可以試開團、看倒數、模擬朋友跟團到成團；只存在那支手機，不會送出，折扣碼也不是真的。正式環境有會員伺服器時不會出現。

也記得在 `mom-app/config.js` 填 `appUrl`（分享連結用的正式網址）、`lineOaUrl`、`shopUrl`。

## 六、安全設計（已通過獨立安全審查）

| 項目 | 做法 |
|---|---|
| 密碼 | scrypt 加鹽雜湊（N=2^14、r=8、p=5，OWASP 建議的最低強度；非同步，不會卡住同一台伺服器上的 LINE 機器人）；舊版雜湊在下次登入時自動升級；最常見的密碼（12345678、password123…）註冊時會被擋下 |
| 登入憑證 | HMAC 簽章、30 天有效；「登出所有裝置」可一次作廢全部（版本號另外存、只會往上加，同時進行的其他請求不會把它改回去） |
| LINE 登入 | 一次性碼（nonce）綁定發起登入的那支手機，別人傳來的「登入連結」會被拒絕；每次登入的 state 只能用一次；回呼也有次數限制；憑證不留在網址列 |
| 暴力猜密碼 | 同一個帳號從同一個網路 10 分鐘最多 10 次；同一個帳號不分網路 10 分鐘 50 次——但**曾經登入成功過的網路不受這個限制**，所以別人故意輸錯也鎖不住本人；計數在共用資料庫（Vercel KV）以單一指令遞增並設定到期，不會變成永久鎖住；IPv6 以 /64 為單位計算 |
| 帳號存在與否 | 登入不論帳號是否存在都花一樣時間 |
| 邀請碼 | 只由伺服器產生，不能搶先註冊別人分享出去的碼；朋友領見面禮時才計入（要同意隱私權政策、帳號 14 天內新建），每個邀請碼每天最多計入 30 位，而且同一個網路最多計入 3 位 |
| 團購揪團 | 折扣碼只在伺服器，只給成團的團員；人數以單一指令增加，同時搶最後一個名額也只會有一人進團；每人每個團購只能在一團；同一個網路最多 3 人跟同一團；開團、跟團有次數限制；團的頁面只顯示團名、人數與剩下時間；刪除帳號時立即退出所有團；團的資料在活動結束 60 天後自動刪除 |
| 驗證碼與忘記密碼 | 6 位數、10 分鐘、最多試 5 次，只存加密雜湊、用過立即刪除；同一個 Email／手機 1 分鐘只能寄一次、1 小時 6 次，同一個網路 1 小時 20 次；註冊和忘記密碼對有沒有帳號的 Email／手機都回一樣的訊息、花差不多的時間、用掉一樣的次數，亂猜驗證碼的結果也一樣（不透露有沒有在用 App）；重設後其他裝置全部登出；註冊時寄不出去會清楚告知 |
| 雙向邀請禮 | 每個帳號只能領一次見面禮（同時送兩個請求也只算一次）；自己輸入的邀請碼不能是自己的、不能是比自己晚註冊的帳號（防止互相邀請），設定後不能改，輸入有次數限制；只算直接邀請（一層）；點數記在手機、不能兌換現金 |
| 在線人數 | 每個網路 10 分鐘最多帶進 6 個新的「在線」連線（一家人的手機），每個連線的心跳也有上限，避免灌假人數；統計結果快取 15 秒省資料庫費用 |
| 錯誤訊息 | 任何格式不對的請求都只回簡短 JSON，不會露出伺服器路徑或程式細節 |
| 不公開的檔案 | 測試、內部文件（docs/）、README 不會被放上網站（伺服器擋下，`.vercelignore` 也不部署） |
| 個資同意與權利 | 沒有勾選同意（目前版本）就不能註冊；同意的版本與時間存在帳號；LINE 新帳號先同意、不同意就刪除；`/me/export` 下載自己的資料（不含密碼）；`/auth/delete` 刪除帳號（密碼帳號要再輸入密碼、有次數限制）；行銷是另外的選項、可隨時關閉 |
| 網路位址 | 次數限制與信任網路的鍵用伺服器密鑰做 HMAC，資料庫裡的值無法還原成網路位址 |
| 資料最少化 | 只存帳號、暱稱、邀請碼；不存任何健康紀錄。「島上的媽媽」只存角色樣式、所在的島（2 分鐘沒心跳就消失）與名稱；祝福牆只存小名、媽媽名稱與祝福 |
| 島上的媽媽 | 身分是手機上的私密金鑰，別人只看到伺服器算出來的代號（不能冒充、不能讀別人收到的互動）；只有四種固定互動、同一對同一種 30 分鐘一次；封鎖後對方的互動默默丟掉；3 人檢舉名稱就隱藏；每個網路每小時最多 6 個新身分 |
| 同週好孕圈 | 只收預產「週」或出生「年月」與回答；只公布總數，3 人以上回答才顯示結果；一人一票、每天一次加油、只能答本週題目；新身分次數限制與島上的媽媽共用 |
| 祝福牆 | 管理金鑰只在媽媽手機（伺服器存雜湊、比對用固定時間比較）；祝福要媽媽確認才公開；開牆、留言都有次數上限，每面牆最多 300 則、400 天後自動刪除 |
| 品牌數據 | 只有次數、沒有是誰；`/admin/stats` 要 `X-Admin-Key`（至少 24 字元、固定時間比對），同一個網路猜錯 10 次就暫停 1 小時；沒設定金鑰時這個網址不存在。App 送來的使用統計（`POST /count`）只收認得的 32 種名稱、每種每批最多 200、同一個網路每 10 分鐘最多 60 批，沒有任何代號 |
| 手機通知 | 只收 Google、Mozilla、Apple、Microsoft 推播服務的 https 位址（不會被拿來打內部網址）；每個會員最多 5 支手機，一支手機只屬於一個帳號；提醒只存「種類和時間」，文字是伺服器固定的，不含預約內容；手機取消訂閱（404／410）就刪除；執行排程要 `MOM_CRON_SECRET` 或 `CRON_SECRET` |
| 家人共用紀錄 | 紀錄在手機上用 AES-GCM 加密（金鑰在手機產生，用 HKDF 分出加密用與編號用兩把），伺服器只存密文、看不到內容也看不到是哪一種紀錄；金鑰只在邀請連結 # 後面（不會送到伺服器）；邀請 7 天失效、移出家人時舊連結立刻失效；每個家庭最多 8 人、6 萬筆；建立者離開就整個刪除；400 天沒用自動刪除 |

**正式推出獎勵前務必設定寄送驗證碼**（0.7.8 起已經做好，只差串接寄信或簡訊服務，見下面「開啟驗證碼」）。設定之後：
- 用 Email／手機註冊要先收驗證碼，別人的 Email／手機搶不走；忘記密碼可以用驗證碼重設（其他裝置會被登出）。
- 見面禮、邀請禮和團購只給驗證過的帳號（LINE 帳號由 LINE 確認），一次性的假帳號拿不到。

在設定之前，或沒有設定的那一種帳號（例如只設定了 Email，手機帳號就不需要驗證碼）：
- 任何人都能用別人的 Email／手機號碼註冊（真正的主人之後就註冊不了，也沒有忘記密碼可以拿回來）；註冊時回「已經註冊過」也會透露這個號碼有沒有在用 App。
- 邀請人數只有「每個網路每天 3 位」的限制，換網路仍可灌；請把邀請人數當參考，不要直接兌換高價值獎品，也不要拿來當 KOL 的唯一成效依據。
- 雙向邀請禮只送好孕點數（記在手機）。若要改成實體贈品或購物金，請先設定驗證碼，並由伺服器發一次性序號；也請先確認公平交易與贈品相關規範。
- `config.js` 的 `shareReward.code` 會被任何人看到（點數也是在手機上計算），只放低價值、可公開的優惠碼；高價值獎品請在驗證完成後由伺服器發放。

### 開啟驗證碼（Email／簡訊）

在 Vercel 的 Environment Variables 設定其中一種（設定了哪一種，那一種帳號註冊時就要輸入驗證碼）：

| 變數 | 用途 |
|---|---|
| `RESEND_API_KEY`、`MOM_MAIL_FROM` | 用 Resend 寄 Email 驗證碼。`MOM_MAIL_FROM` 例如 `易家做媽媽 <no-reply@你的網域>`（網域要先在 Resend 驗證） |
| `TWILIO_ACCOUNT_SID`、`TWILIO_AUTH_TOKEN`，加上 `TWILIO_FROM` 或 `TWILIO_MESSAGING_SERVICE_SID` | 用 Twilio 寄簡訊驗證碼（號碼自動轉成 +886 格式） |
| `MOM_CODE_WEBHOOK_URL`（https）、`MOM_CODE_WEBHOOK_SECRET` | 用你們自己的系統寄（例如三竹、every8d 簡訊或公司的寄信服務）：伺服器會 POST `{channel, to, code, purpose, text}`，並在 `X-Mom-Signature` 放 `sha256=` 加上用 SECRET 算的 HMAC，請先驗證簽章再寄出 |
| `MOM_CODE_ECHO=1` | 只限測試：驗證碼直接顯示在畫面上（標「測試環境」），正式環境（Vercel 或 `NODE_ENV=production`）一律無效 |

設定好之後，請用自己的 Email／手機實際註冊一次，確認收得到驗證碼。也記得把寄送服務商寫進 `config.js` 的 `privacy.processors`（隱私權政策會列出）。

### 品牌數據後台（0.9.0）

在 Vercel 設定 `MOM_ADMIN_KEY`（至少 24 個字元的亂數，例如 `openssl rand -base64 32`），然後用電腦或手機打開 App 的 `#/admin`，輸入這組金鑰。

- 看得到：會員總數、現在在線、新註冊（每天的長條圖、Email／手機／LINE 各多少）、App 開啟次數、成功邀請、邀請禮領取、團購的開團／參加／成團與成團率、祝福牆、好孕圈、島上打招呼、推播、家人共用、刪除帳號，以及「同意行銷訊息」的人數。
- 0.9.3 起還有：今天／本週／本月在用的手機（會員和沒註冊的都算）和新手機、新使用者選的階段（備孕／懷孕／育兒、先看範例資料）、記錄了什麼（尿布、親餵、瓶餵、睡眠、擠奶、副食品、其他）、滴雞精時光打卡、從品牌頁到官網／LINE（每支手機每天各算一次）、分享管道（LINE、IG、Facebook、Threads、存圖片、複製連結）、同週好孕圈的媽媽（預產期在哪個月、寶寶多大）、功能使用（夜奶陪伴、成長回顧、寶寶月照、好孕島蓋章、問答搜尋、家族週報）。
- 近 7 天／近 30 天切換，每個數字都和前一段時間比較；可以匯出 CSV（Excel 打得開）。
- 只有次數，沒有姓名、帳號或電話。新註冊以會員名單為準；其他數字從 0.9.0 開始累計，上面 0.9.3 那些從 0.9.3 開始。
- 0.9.3 那些數字是 App 送來的「次數」：手機自己記（例如「尿布 +1」），跟著 App 每分鐘的連線一起送，只有名稱和數字；「在用的手機」由手機自己記得今天／這週／這個月送過沒有，伺服器不需要分辨是哪一支。範例資料裡做的事（只算「選了範例資料」）、試閱本的試玩、後台本身都不算；沒網路時先存在手機，連上再送。
- 金鑰只存在那台裝置（預設只到關掉分頁為止，勾「記住這台裝置」才會留著）。不要把金鑰寫進 `config.js` 或分享出去。
- 沒有連上會員伺服器的地方（例如網頁預覽版）會顯示清楚標示的範例數字，只是讓你看版面。

### 開啟手機通知（0.9.0）

會員可以在「我的 → 提醒設定 → 手機通知」打開，App 關著也收得到：團購進度（有人加入、差 1 人、成團）、餵奶／預約／滴雞精提醒、家人共用的消息。

1. 產生 VAPID 金鑰：在專案資料夾執行 `npx web-push generate-vapid-keys`。
2. 在 Vercel 設定：

| 變數 | 用途 |
|---|---|
| `MOM_VAPID_PUBLIC`、`MOM_VAPID_PRIVATE` | 上一步產生的兩把金鑰（私鑰不要外流） |
| `MOM_VAPID_SUBJECT` | `mailto:你們的客服信箱` 或 `https://官網`，推播服務有問題時聯絡用 |
| `MOM_CRON_SECRET`（或 `CRON_SECRET`） | 送出到時間的提醒用。Vercel Cron 會自動帶 `CRON_SECRET` |

3. 排程送提醒（每分鐘一次，二選一）：
   - Vercel Pro：在 `vercel.json` 加 `"crons": [{ "path": "/mom-app/api/push/run", "schedule": "* * * * *" }]`。（Hobby 方案的 Cron 一天只能一次，加了會部署失敗。）
   - 用 Upstash QStash 的排程，每分鐘 `POST https://你的網址/mom-app/api/push/run`，標頭帶 `Authorization: Bearer 你的 MOM_CRON_SECRET`。
   - 沒有設定排程時，只要有人開著 App，伺服器每分鐘也會順便送一次；但半夜沒人開 App 時提醒會晚到，正式上線請設定排程。
4. iPhone 要 iOS 16.4 以上、先把 App「加入主畫面」，從主畫面打開後才能開啟通知；App 會自己說明。

**LINE 通知（選用）**：用 LINE 登入的會員可以選擇讓團購進度和家人消息由官方帳號傳 LINE（不用推播，iPhone 沒加主畫面也收得到）。
- 設定 `MOM_LINE_MESSAGING_TOKEN`（官方帳號 Messaging API 的 channel access token）和 `MOM_PUBLIC_URL`（訊息裡的連結）。
- 官方帳號的 Messaging API channel 和 LINE Login channel 要在同一個 provider 底下，使用者代碼才會一樣；會員要先加官方帳號好友才收得到。
- 每則推播訊息會用掉官方帳號的訊息額度。

### 家人共用紀錄（0.9.0）

不需要另外設定（用的是會員伺服器的資料庫），會員都能用：「我的 → 家人共用紀錄」。
- 建立的人勾選同意後建立，用 LINE／複製連結／QR 邀請家人；家人登入後按連結就能加入（新手機也可以，不用先設定）。
- 會同步：寶寶資料（不含寶寶照片）、所有日常紀錄、成長、疫苗與健檢、發展里程碑、母乳庫存。不會同步：懷孕紀錄、產檢日記、月照照片、媽媽自己的健康紀錄和設定。
- 紀錄在手機上加密後才上傳，伺服器（包括我們）打不開；邀請連結就是鑰匙，請提醒會員只傳給家人。
- 隱私權政策已加上「家人共用紀錄」「手機通知」「使用統計」三列。這些是新的資料處理，正式上線前請法務確認，並決定要不要更新隱私權政策版本（`mom-api/policy.js` 的 `POLICY_VERSION` 和 App 的 `App.privacy.VERSION` 一起改），讓舊會員重新同意。
