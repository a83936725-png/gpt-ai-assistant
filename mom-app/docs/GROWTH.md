# 裂變手冊：讓媽媽習慣分享

## 一、App 裡已經有的分享機制

| 機制 | 內容 |
|---|---|
| 分享面板 | LINE、Instagram、Facebook、Threads、複製連結、系統分享；每個連結都帶**邀請碼**與 `utm_source`／`utm_campaign` |
| 分享卡（1080×1920，IG 限時動態尺寸） | 孕週卡、寶寶成長卡、出生卡、滿月／百日／收涎／度晬、里程碑、滴雞精連續打卡、好孕島稱號、坐月子、本週重點、文章卡；卡片上有 LOGO、QR Code、邀請碼、hashtag |
| IG 分享 | 手機：透過系統分享把圖片直接送到 IG（限時動態／貼文／私訊）；電腦：自動下載圖片＋複製文字，提示加「連結」貼紙 |
| 關鍵時刻提醒 | 新孕週、寶寶出生、滿月／百日／4 個月收涎／1 歲度晬、產後滿月、新里程碑、打卡連續 7／14／30／60／100 天、好孕島新稱號、集滿 3 顆愛心 → 輕提示「做成分享卡」（每天最多一次，可「不要再提醒這類」） |
| 分享按鈕 | 首頁寶寶卡、孕週卡、孕產路線圖每個階段、坐月子、好孕島每篇小知識、問答、本週重點、品牌頁、外出計畫 |
| 邀請好友頁 | 邀請碼、QR、LINE 邀請、分享卡圖庫、好孕點數與獎勵、我的分享統計 |
| 好物願望清單 | 媽媽把「想請人送」的寶寶用品分享給親友；親友免註冊打開清單（帶邀請碼），按「我想送這個」用 LINE 回覆，頁尾邀請親友自己也開始用。每一項好物也能做成「怎麼挑／先別買」分享卡 |
| 邀請落地 | 朋友打開連結 → 歡迎頁顯示「XX 邀請你一起使用」、註冊時自動帶入邀請碼 |
| 好孕點數 | LINE／FB／Threads +10、IG 分享卡 +20、邀請連結 +15、島上愛心 +5（每天上限 60）；30 點徽章、60 點金色印章框、100 點品牌好禮（在 `config.js` 的 `shareReward.code` 填優惠碼） |
| 成功邀請人數 | 登入後，朋友用你的邀請碼註冊會計入（伺服器計算，不是自己按的次數） |
| 社群人數 | 首頁、歡迎頁、登入頁顯示「現在 N 位在線上・已有 M 位媽咪註冊」（真實數字；連不到伺服器就不顯示） |
| 祝福牆 | 滿月、百日、週歲（懷孕時是好孕加油牆）：媽媽把連結傳到家族群組，親友**免下載、免註冊**留下祝福；連結帶邀請碼，頁尾邀親友自己也試試；首頁在對的時間提醒開牆 |
| 島上的媽媽 | 加入後在好孕群島看到同階段的媽媽、互相揮手送愛心；島上沒人時有「邀請朋友一起逛」 |
| 同週好孕圈 | 同一週預產／同月出生的媽媽每週一題、分享心情、互相加油；首頁直接作答（每週回來的理由）；圈裡只有自己時提示「邀請朋友加入」 |

## 二、品牌端要做的（App 外）

1. **IG 留言送連結**（參考 Reel 的 2,909 則留言）：品牌 IG 發「留言 +1 送你孕週卡／外出包清單」，用 Meta 官方自動私訊或合作工具回覆**帶邀請碼的連結**（`utm_source=instagram&utm_campaign=ig-comment`）。
2. **LINE 官方帳號關鍵字回覆**：「做媽媽」「孕週」「外出包」→ 回 App 連結；把 `config.js` 的 `lineOaUrl` 填好，App 內「LINE 諮詢」鈕會導到官方帳號。
3. **門市／產後護理之家**：桌卡放 App QR（用邀請頁的 QR，或 `utm_source=store`）。
4. **KOL／醫師合作**：每位合作對象一個專屬邀請碼，邀請頁的「成功邀請人數」就是成效。
5. **獎勵兌現**：好孕點數 100 點顯示的優惠碼，到官網結帳使用；若要防止重複使用，建議用一次性序號（第二階段：由後端依帳號發放）。

## 三、要看的數字

| 指標 | 怎麼看 |
|---|---|

| 每位使用者邀請成功數 | `GET /mom-app/api/me`（`referrals`） |

## 四、隱私與法規

- 分享卡**預設不放寶寶照片**，寶寶名字可隱藏；**醫療紀錄（看診、用藥、體溫、產後狀況）不做成公開分享卡**。
- 邀請連結只帶邀請碼與暱稱（可在分享面板關掉名字）。
- 「島上的媽媽」預設不開；加入後只分享畫的 Q 版角色、所在的島、自己取的名稱，不分享照片、週數、寶寶資料與紀錄；陌生人之間只有固定四種互動，沒有私訊與留言。
- 「同週好孕圈」預設不加入；只送出預產期是哪一週（不是日期）或寶寶出生年月，以及匿名的回答；結果只顯示總數，3 位以上回答才公布。
- 祝福牆的祝福要媽媽按「顯示」才公開；名稱與祝福裡的電話、連結、Email、LINE ID 會被伺服器拿掉。
- 品牌文案依食品安全衛生管理法第 28 條，不宣稱療效。
- 點數獎勵若改成抽獎或高額贈品，請先確認公平交易與贈品相關規範。

## 五、開啟會員功能（登入、人數、邀請計數）

會員 API 跟著這個 repo 的伺服器一起部署（`mom-api/`，掛在 `/mom-app/api`）。在 Vercel 專案的 Environment Variables 設定：

| 變數 | 必填 | 說明 |
|---|---|---|
| `MOM_AUTH_SECRET` | ✅ | 至少 32 字的隨機字串（用來簽登入憑證），例如 `openssl rand -hex 32`；少於 32 字在任何環境都不會被使用；正式環境沒設定時，登入會自動關閉（人數照常顯示） |
| `KV_REST_API_URL`、`KV_REST_API_TOKEN` | ✅ | 在 Vercel 加入 KV／Upstash Redis 整合後自動產生（沒設定時用記憶體，人數會標「測試環境」且重啟就歸零） |
| `LINE_LOGIN_CHANNEL_ID`、`LINE_LOGIN_CHANNEL_SECRET` | 選填 | 在 LINE Developers 建立 LINE Login channel；Callback URL 填 `https://你的網域/mom-app/api/auth/line/callback`，填好後登入頁才會出現「用 LINE 登入」 |
| `MOM_PUBLIC_URL` | 用 LINE 登入時必填 | App 的正式網址（例如 `https://你的網域/mom-app/`），LINE 登入完成後導回這裡；正式環境沒填時 LINE 登入會關閉（不讓網址由請求的 Host 決定） |
| `MOM_TRUST_PROXY` | 視部署 | 伺服器前面有幾層代理（nginx、負載平衡器）就填幾，例如 `1`，次數限制才會以每位使用者計算；直接對外或在 Vercel 上請不要填 |
| `MOM_ALLOWED_ORIGINS` | 選填 | 如果 App 放在別的網域，填那個網域（逗號分隔）讓它能呼叫 API |

也記得在 `mom-app/config.js` 填 `appUrl`（分享連結用的正式網址）、`lineOaUrl`、`shopUrl`。

## 六、安全設計（已通過獨立安全審查）

| 項目 | 做法 |
|---|---|
| 密碼 | scrypt 加鹽雜湊（N=2^14、r=8、p=5，OWASP 建議的最低強度；非同步，不會卡住同一台伺服器上的 LINE 機器人）；舊版雜湊在下次登入時自動升級；最常見的密碼（12345678、password123…）註冊時會被擋下 |
| 登入憑證 | HMAC 簽章、30 天有效；「登出所有裝置」可一次作廢全部（版本號另外存、只會往上加，同時進行的其他請求不會把它改回去） |
| LINE 登入 | 一次性碼（nonce）綁定發起登入的那支手機，別人傳來的「登入連結」會被拒絕；每次登入的 state 只能用一次；回呼也有次數限制；憑證不留在網址列 |
| 暴力猜密碼 | 同一個帳號從同一個網路 10 分鐘最多 10 次；同一個帳號不分網路 10 分鐘 50 次——但**曾經登入成功過的網路不受這個限制**，所以別人故意輸錯也鎖不住本人；計數在共用資料庫（Vercel KV）以單一指令遞增並設定到期，不會變成永久鎖住；IPv6 以 /64 為單位計算 |
| 帳號存在與否 | 登入不論帳號是否存在都花一樣時間 |
| 邀請碼 | 只由伺服器產生，不能搶先註冊別人分享出去的碼；每個邀請碼每天最多計入 30 位，而且同一個網路最多計入 3 位 |
| 在線人數 | 每個網路 10 分鐘最多帶進 6 個新的「在線」連線（一家人的手機），每個連線的心跳也有上限，避免灌假人數；統計結果快取 15 秒省資料庫費用 |
| 錯誤訊息 | 任何格式不對的請求都只回簡短 JSON，不會露出伺服器路徑或程式細節 |
| 不公開的檔案 | 測試、內部文件（docs/）、README 不會被放上網站（伺服器擋下，`.vercelignore` 也不部署） |
| 資料最少化 | 只存帳號、暱稱、邀請碼；不存任何健康紀錄。「島上的媽媽」只存角色樣式、所在的島（2 分鐘沒心跳就消失）與名稱；祝福牆只存小名、媽媽名稱與祝福 |
| 島上的媽媽 | 身分是手機上的私密金鑰，別人只看到伺服器算出來的代號（不能冒充、不能讀別人收到的互動）；只有四種固定互動、同一對同一種 30 分鐘一次；封鎖後對方的互動默默丟掉；3 人檢舉名稱就隱藏；每個網路每小時最多 6 個新身分 |
| 同週好孕圈 | 只收預產「週」或出生「年月」與回答；只公布總數，3 人以上回答才顯示結果；一人一票、每天一次加油、只能答本週題目；新身分次數限制與島上的媽媽共用 |
| 祝福牆 | 管理金鑰只在媽媽手機（伺服器存雜湊、比對用固定時間比較）；祝福要媽媽確認才公開；開牆、留言都有次數上限，每面牆最多 300 則、400 天後自動刪除 |

**正式推出獎勵前務必補上**：Email／簡訊驗證碼與忘記密碼流程 —— 目前尚未實作（需要串接寄信或簡訊服務）。在那之前：
- 任何人都能用別人的 Email／手機號碼註冊（真正的主人之後就註冊不了，也沒有忘記密碼可以拿回來）；註冊時回「已經註冊過」也會透露這個號碼有沒有在用 App。
- 邀請人數只有「每個網路每天 3 位」的限制，換網路仍可灌；請把邀請人數當參考，不要直接兌換高價值獎品，也不要拿來當 KOL 的唯一成效依據。
- `config.js` 的 `shareReward.code` 會被任何人看到（點數也是在手機上計算），只放低價值、可公開的優惠碼；高價值獎品請在驗證完成後由伺服器發放。
