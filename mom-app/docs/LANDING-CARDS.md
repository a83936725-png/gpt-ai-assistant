## 二、六種卡片：名稱、用途、做法、提示詞

每一種都遵守同一組規則（見第三節）：**靜止時就是完整的畫面、只在畫面上時才動、只動 transform 和 opacity、減少動態效果時完全不動。**

### 01 編號裝置展示（numbered device showcase）

- **什麼時候用**：講「步驟」或「流程」：三步上手、註冊流程、功能導覽。
- **我們用在**：三步上手（打開就能用 → 一鍵記錄 → 全家一起顧），三張都是 App 真實畫面。
- **怎麼做**：
  - 大號空心數字（`-webkit-text-stroke`）壓在手機左上角；輪到它時數字填滿紫色、手機往上浮 10px。
  - 一個 6 秒的 CSS 動畫，三張用 `animation-delay: calc(var(--i) * 2s)` 錯開，就變成 01 → 02 → 03 輪流亮起。
  - 桌機版手機「插在一條線上」（下半部被 2px 黑線切掉），說明文字不會被擠到畫面外；手機版改成左圖右文，數字放在文字上方。
- **提示詞關鍵字**：`numbered device mockups 01/02/03, outline numerals that fill when active, staggered highlight loop, phones cropped by a baseline rule`

### 02 抽象賣點卡（abstract feature cards）

- **什麼時候用**：功能「看不見」，截圖講不清楚：預測、加密、同步、計算。
- **我們用在**：A 接下來（下一餐的錶盤）、B 端對端加密（一個封包從媽媽手機經過伺服器到爸爸手機，經過伺服器時變成亂碼）、C 成長曲線（寶寶的線畫在 WHO 參考範圍裡）。
- **怎麼做**：
  - 每張卡是一個小 SVG，`pathLength="100"` 加 `stroke-dasharray/dashoffset` 畫線、畫弧。
  - 封包用 `transform: translate()` 走三段路，文字在 18％／67％ 一瞬間切換（不要兩段文字疊在一起淡入淡出，會糊）。
  - **動畫的第 0 幀＝畫好的完整圖**：還沒捲到時、或減少動態效果時，看到的都是完整的圖，不是一張空白卡。
- **提示詞關鍵字**：`abstract feature cards, looping SVG micro-diagrams, stroke-dashoffset line drawing, resting frame is the finished diagram`

### 03 弧形扇卡（arc fan cards）

- **什麼時候用**：一組「同類但不同」的東西：紀錄類型、方案、口味、尺寸。
- **我們用在**：親餵、瓶餵、擠奶、尿布、睡眠、體溫、副食品七張卡；點一張，下面的試玩 App 就打開那種紀錄。
- **怎麼做**：
  - 每張卡 `transform-origin: 50% calc(100% + 支點距離)`，再 `rotate((i - 3) × 角度)`：支點在卡片下方很遠，七張卡就排成一把手上的牌。
  - 一次升起一張（`translateY(-22px)`），1.5 秒換下一張；滑鼠指著或鍵盤停在上面就暫停。
  - 手機版：卡片變窄、小字只在升起的那張顯示；**手指左右滑就一張一張翻**（Resn 式的手感）。
- **提示詞關鍵字**：`arc fan / hand of cards, transform-origin far below, rotate by index from the middle, active card lifts, swipe to flip on touch`

### 04 立體環視卡（3D ring carousel）

- **什麼時候用**：「一個世界裡有很多地點」：地圖、館別、系列商品。這是整頁最「Active Theory」的地方。
- **我們用在**：好孕島挑 12 個站點（葉酸果園、害喜小屋、產檢診所、胎動小站、待產包倉庫、產房燈塔、月子溫泉、哺乳咖啡館、睡眠森林、副食品廚房、學步小路…），App 裡一共 35 個站點。
- **怎麼做**：
  - 真的 3D：外層 `perspective`，環 `transform-style: preserve-3d`，每張卡 `rotateY(i × 30°) translateZ(半徑)`。
  - 整個環往後推 `translateZ(-半徑)` 再 `rotateX(-9deg)`（從斜上方看，才看得出是一個「環」），背面 `backface-visibility: hidden`，越後面越淡。
  - 用 `requestAnimationFrame` 慢慢轉（約 33 秒一圈），**只在畫面上時轉**；可以拖（有慣性）、方向鍵、← → 按鈕，停下來會對齊一張卡。
  - 沒有 JavaScript 時，同一份 HTML 退回成可以左右滑的一排卡片。
- **提示詞關鍵字**：`3D carousel ring, perspective + preserve-3d, rotateY(i*360/n) translateZ(r), slight top-down tilt, drag with inertia and snap, keyboard arrows`

### 05 精選畫廊卡（featured gallery cards）

- **什麼時候用**：同一個東西的幾種樣子：相框、配色、款式。
- **我們用在**：寶寶月照四種相框（奶油、花圈、拍立得、夜空），圖都是 App 自己畫出來的。
- **怎麼做**：
  - 一張大圖＋四張小圖。每 3.6 秒換下一張：大圖交叉淡入，同時從 1.04 慢慢縮回 1（很輕的 Ken Burns）。
  - 目前那張小圖下面有一條進度線（像 IG 限動），每次換圖重新跑。
  - 點小圖就換成大圖，自動播放停 9 秒。
- **踩到的坑**：`<img width height>` 的屬性會變成 CSS 高度，蓋掉 `aspect-ratio`，小圖被拉成長條 → 加 `height: auto`。
- **提示詞關鍵字**：`featured gallery: one large + thumbnails, crossfade with subtle zoom, story-style progress bar under the active thumb, tap to choose`

### 06 彩虹扇卡（rainbow fan cards）

- **什麼時候用**：「選一個顏色／主題」：配色、主題、季節款。
- **我們用在**：七種分享卡配色，照彩虹順序排：莓果、蜜桃、奶茶、薄荷、霧藍、夜空、紫芋（卡片圖也是 App 自己畫的）。
- **怎麼做**：
  - 和 03 一樣是轉的，但支點放在舞台底部、角度開到 ±57°，變成一道拱形的彩虹。
  - 一道「波浪」：每張卡用獨立的 `translate` 屬性上下浮動，延遲 0.22 秒一張（不會和 `transform` 的轉動打架）。
  - 點一張就挑起來（放大、顯示名稱），波浪停下；再點一次放回去。
- **提示詞關鍵字**：`rainbow arch fan, cards radiating from one pivot in spectrum order, staggered wave, tap to pick and enlarge`

### 加碼：整頁變夜晚（場景轉換）

- 讀到「03:12 夜奶陪伴」時，整頁的紙、字、紫色慢慢換成 App 夜間模式的顏色，手機後面亮起一盞暖黃的燈；離開這段再亮回來。
- 做法：顏色都是 CSS 變數，用 `@property` 註冊成 `<color>` 才能做過渡；`IntersectionObserver` 看到這段佔畫面 42％ 以上就在根元素加 `data-scene="night"`。
- 減少動態效果時不換顏色（整頁突然變色反而更刺激）。

## 三、所有卡片共用的規則

| 規則 | 做法 |
|---|---|
| 靜止時就完整 | 動畫第 0 幀＝完成的畫面；JavaScript 沒跑、截圖、縮圖時看起來都正常 |
| 只在畫面上時動 | `IntersectionObserver` 加 `.on`；CSS 動畫只寫在 `.on` 底下；3D 環的 `requestAnimationFrame` 離開畫面就停 |
| 只動 transform／opacity | 不動寬高、不動 top/left，手機也順 |
| 減少動態效果 | 迴圈、滑入、整頁變色全部不做；按鈕、拖曳照樣可以用 |
| 不改捲動速度 | 用瀏覽器原本的捲動；「帶我去」才平滑捲到試玩區 |
| 摸得到 | 卡片都是真的按鈕，有 `aria-pressed`、標籤；3D 環可以用方向鍵 |
| 效能預算 | 首屏圖片 187 KB（預算 1 MB）；其他圖片 `loading="lazy"`；試玩 App 捲到附近才載入 |
| 無障礙 | axe（WCAG 2 A／AA）淺色、深色、手機、夜晚場景都 0 個問題（3D 環轉到側邊、刻意變淡的卡不檢查對比；轉到正面的那張有檢查） |

## 五、五個階段，每一階段的修改意見（實際做過的）

### 1. 資訊架構

- 先決定「每一種卡片都要對應一個真的功能」，不做只有好看的卡。
- 60／40 的分界放在「試玩」：前面講故事，後面讓她自己點。
- 每一段都留一個進到試玩的入口（「在試玩裡打開」、點扇形卡、帶我去）。

### 2. 首頁視覺（封面）

| 問題 | 修改 |
|---|---|
| 「直接試玩 App」按鈕的字看不見 | `.mag a { color: inherit }` 的權重比按鈕高 → 改成 `:where(.mag) a`，按鈕自己的顏色才贏 |
| 直排標語跑到內容欄外面，看起來是掉出來的 | 給它一欄（第 12 欄）、加一條細線，和手機並排 |
| 副標在「一位／媽媽」中間斷行 | 兩句各自一行（寬螢幕），手機版照常排 |
| 定價貼紙在深色模式變成暗黃色、字看不清 | 貼紙固定用實色黃 `#ffe866`，字固定深色 |

### 3. 功能頁（六種卡片）

| 問題 | 修改 |
|---|---|
| 月照畫廊小圖被拉成長條、大圖掉到最下面 | 小圖加 `height: auto`（img 的 height 屬性蓋掉 aspect-ratio）；兩欄改成置中對齊 |
| 弧形扇卡外側兩張轉太斜、像散掉 | 支點放更遠（420px）、角度改 9°，扇子變平緩 |
| 立體環看起來像幾張平平的卡 | 半徑加大、從斜上方看（rotateX -9°）、背面隱藏 |
| 24 小時專題左邊一大片空白 | 每站加一個側欄，放真的內容：夜奶畫面輪流出現的四句話、交接卡上有什麼、首頁的六個一鍵紀錄、四種相框、回顧會講到的六件事 |
| 三步上手的手機太高，說明文字被擠到畫面外 | 桌機版手機「插在一條線上」，只露上半部 |
| 加密封包的兩段文字疊在一起糊掉 | 文字改成一瞬間切換 |
| 帶淺紫底色的段落左右有 8px 白邊 | 補上 `body { margin: 0 }` |

### 4. 手機版

| 問題 | 修改 |
|---|---|
| 三步上手的大數字被手機圖蓋住 | 手機版把數字放到文字上方 |
| 七張扇形卡擠在一起、小字互相重疊 | 卡片變窄，小字只在升起的那張出現；加「手指左右滑」一張一張翻 |
| 試玩區在手機上可能卡住捲動 | 試玩框高度最多 74％ 螢幕，下面提示「手指放在框框外面滑，就能繼續往下看」，另外有「開新分頁玩」 |
| 320px 小手機 | 每一段都檢查沒有左右捲動 |

### 5. 實際操作測試（`tests/landing.playwright.cjs`，64 項）

- 五個試玩任務都「真的做」：從故事點進交接卡、點扇形卡記一筆尿布並儲存、按首頁的親餵＋、帶我去成長回顧、帶我去夜奶陪伴 → 完成 5／5。
- 重新開始會清掉試玩的紀錄；**她自己 App 的資料從頭到尾一個字都沒變**（測試先在真的 App 存一個名字，最後比對）。
- 減少動態效果：沒有任何動畫在跑、圖都在、整頁不變色、3D 環不自己轉但按鈕可以轉。
- 測試截圖順便抓到兩個 **App 本身** 的問題，已修：
  1. 夜奶陪伴在沒有會員服務時多出一行「null」（DOM 的 `append(null)` 會印出 "null"）。
  2. 白天手動打開夜奶陪伴顯示「晚上 14:12」，冬天日出前 05:40 也是「晚上」→ 改成依時段顯示（凌晨／清晨／早上／中午／下午／晚上）。

## 七、「AI 感」自我檢查

| 常見的 AI 模板感 | 這頁的做法 |
|---|---|
| 紫粉漸層、毛玻璃、大顆模糊光球 | 白紙＋品牌紫實色＋一支螢光筆黃；夜奶手機後面的橘色光暈也拿掉了 |
| 置中大標＋兩顆按鈕＋三張圖示卡 | 雜誌版型：刊頭、封面標題、頁眉頁碼、不對稱欄位；封面只留一個按鈕，另一個是文字連結 |
| 斜放、懸浮、帶陰影的兩支手機 | 封面改成一張像照片一樣裁切的 App 實際畫面，附圖說 |
| emoji 當圖示或標點 | 頁面上沒有 emoji；七種紀錄用 App 自己的線條圖示 |
| 假的評價、假的使用人數 | 沒有任何數字是編的；在線人數寫「有會員服務時，還會顯示這個時間有幾位媽媽也醒著」 |
| 每張卡都是同樣的大圓角＋陰影 | 雜誌段落用細線和直角；只有「產品」的試玩面板用 App 的圓角 |
| 一直在動（為了展示而動） | 除了 03:12 變夜晚，什麼都不自己動；要點、要拖才會動 |
| 標題在描述元件（「七種紀錄，一把扇子」） | 標題講她做的事（「單手按一下就記好」「傳到家族群組的那張圖」） |
| 同一件事講五遍、每段一排小標籤 | 每件事只講一次；小標籤換成 App 裡的原話（「依最近 16 次餵食與寶寶月齡估算」） |

**還沒改、要真的素材或你決定的**
- **真的照片**（最大的一步）：封面、月照、分享卡都還沒有真照片。建議拍一組有肖像授權的情境照（凌晨小夜燈下抱著寶寶、手機在手上），封面換一張圖就好（`lp/index.html` 的 `cover-shot`）。
- **刊頭字**：「易家做媽媽」目前是 Google 字型直接打上去，正式版建議請字體設計師修字，當 logo 用。
- **小滴**：目前是程式畫的；品牌若要長期用，建議請插畫家正式設計，或拿掉。

- **分享卡的設計**（漸層＋泡泡＋三格數字）和**整個 App 的字級**（36 種字級收成 5 級）：範圍大，留到下一輪。
