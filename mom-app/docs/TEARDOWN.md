**是什麼**：一個把備孕知識做成「可以逛的小島」的網站（island.ivfdrhsieh.com）。作者說架構參考自 puma.taipei/heart，知識內容來自他自己的官網。

| 右側控制列 | 全景、角色、清單、旅程、晚上（日夜切換）、秋季（季節切換）、**預約**（導流到看診） |
| 底部 | 「好孕日誌」新聞跑馬燈 |

**成效**：上線幾天約 9.8K 次瀏覽、261 讚、**142 次分享**（分享數很高 → 內容有「想傳給別人看」的特性）。

**可以學的重點**
1. 把衛教「遊戲化」：讓人主動探索，而不是被動讀文章。
2. 地圖＝目錄：每個景點就是一個主題，清單模式給趕時間的人。
3. 有收集感（旅程）、有彩蛋（會說話的寶寶），提高停留時間與分享。
4. 最後有轉換按鈕（預約）→ 對品牌來說就是「導購／加 LINE」。

## 三、產品定位（給易家滴雞精）

- **品牌任務**：滴雞精的主要使用時機（備孕、孕期、坐月子、哺乳）剛好就是這個 App 的使用旅程。App 是每天會打開的「工具」，品牌出現在對的時刻，而不是廣告。
- **每日接觸點**：「今天的滴雞精時光」打卡卡片（首頁）＋可設定的每日提醒 → 養成習慣、提高回購。
- **導流**：品牌頁與島上小舖的「官網選購」「加入 LINE 好友」按鈕（`config.js` 設定）。
- **可延伸的會員機制（第二階段）**：連續打卡集點 → 兌換優惠券；LINE 官方帳號推播。

### ⚠️ 法規與信任（很重要）

1. **食品不能宣稱療效**（食品安全衛生管理法第 28 條）：App 內所有滴雞精相關文字都只談「習慣、休息、心情、保存加熱方式」，沒有「促進傷口癒合、補氣、退奶」這類說法。之後新增文案也請維持。
2. **健康資料屬於敏感個資**（個人資料保護法第 6 條：醫療、健康檢查等）：MVP 版本資料只存在使用者自己的手機，不上傳。第二階段要做雲端同步時，需要明確的告知同意、加密與存取控管。
3. **醫療資訊**：所有衛教內容標示「一般衛教資訊，不能取代專業醫療建議」，疫苗／產檢時程都註明「以疾管署／國健署公告及醫師安排為準」。上線前建議請合作的醫師或營養師審閱內容。

## 四、技術架構

- **純前端 PWA**：HTML + CSS + 原生 JavaScript，不需要編譯、不需要伺服器、不需要資料庫。可以「加入主畫面」當 App 用，也能離線使用。
- **資料**：存在瀏覽器 localStorage（`yijia-mom-app-v1`），結構見 `js/store.js`。
- **模組化**：每個功能是一個檔案，透過 `App.screen()`／`App.homeCard()`／`App.tool()` 註冊。

```
mom-app/
├── index.html            入口
├── config.js             ★ 品牌設定（名稱、LOGO、官網、LINE 連結）
├── manifest.webmanifest  PWA 設定
├── sw.js                 離線快取＋通知點擊
├── assets/               LOGO、App 圖示
├── css/                  base（設計系統）＋各模組樣式
├── js/
│   ├── core.js           日期、孕週、排卵、預測、母乳保存、WHO 百分位（有單元測試）
│   ├── store.js          資料儲存
│   ├── ui.js             UI 元件（底部抽屜、提示、表單）＋模組註冊
│   ├── app.js            路由、分頁列、即時計時器
│   ├── data/             紀錄類型、好孕島內容、疫苗/里程碑/WHO 表、孕週資料
│   └── modules/          home 首頁｜babylog 紀錄｜milk 母乳庫存｜island 好孕島｜
│                         health 成長健康｜pregnancy 備孕懷孕｜brand 品牌｜me 我的
├── tests/                core.test.js 單元測試｜e2e／extended／journey.playwright.cjs 瀏覽器測試
└── docs/TEARDOWN.md      本文件
```

### 換成正式 LOGO

目前的 LOGO 是依你提供的圖重新描繪的向量檔（`assets/logo.svg`、`assets/logo-full.svg`）。若要用原始檔：
1. 把原圖放到 `mom-app/assets/logo.png`（建議透明背景、正方形）
2. 打開 `config.js`，把 `logo: 'assets/logo.svg'` 改成 `logo: 'assets/logo.png'`

### 部署（任選一種，免費）

- **Vercel**：新增一個專案 → 選這個 GitHub repo → Root Directory 設為 `mom-app` → Framework 選 Other → Deploy。
- **GitHub Pages / Netlify**：把 `mom-app` 資料夾當成靜態網站發佈即可。
- 本機預覽：`cd mom-app && python3 -m http.server 8080`，打開 http://localhost:8080

> 注意：iPhone 要收到通知，需先用 Safari「加入主畫面」，再從主畫面打開 App 開啟通知（iOS 16.4 以上）。

## 五、第二階段路線圖

| 優先 | 項目 | 做法 |
|---|---|---|
| 1 | **LINE 登入＋雲端同步＋家庭群組** | LINE Login／LIFF 取得使用者；後端（例如 Vercel Functions + Postgres，或 Firebase／Supabase）存資料；家庭邀請連結讓多人即時共用同一個寶寶的紀錄 |
| 2 | **關閉 App 也能收到推播** | Web Push（VAPID）＋排程；或改用 LINE 官方帳號推播（品牌也能一起經營） |
| 3 | **串接這個 repo 的 LINE 機器人** | 在 LINE 對話裡打「瓶餵 120」就寫入紀錄；也可以接上原本的 AI 助理做育兒問答（需加醫療安全護欄） |
| 4 | **寶寶攝影機** | WebRTC 點對點視訊＋信令伺服器（必要時 TURN），舊手機／平板當攝影機 |
| 5 | **會員點數** | 滴雞精打卡集點 → 優惠券／官網折扣碼 |
| 6 | **上架 App Store／Google Play** | 用 Capacitor 包裝，或 Android 用 TWA |
| 7 | **好孕島升級** | three.js 3D 版、角色選擇、更多隱藏彩蛋、醫師／營養師專欄 |

## 九、孕期到出生完整流程（v0.4）

把「懷孕 → 生產 → 坐月子」串成一條路，每一步都有**紀錄**和**注意事項**。逐步操作截圖請看 [FLOW.md](FLOW.md)。

| 新功能 | 內容 |
|---|---|
| 🗺️ 孕產路線圖 | 懷孕初期／中期／後期／足月待產／生產／產後坐月子 6 個階段，自動標出「你在這裡」；每階段有「該做的事」清單（可勾選、可直接前往工具）與「注意事項」（就醫警訊）、小提醒、求助專線 |
| 📝 身體狀況日記 | 懷孕期間記錄症狀（22 種，⚠️ 標示警訊）、血壓、心情、備註 |
| 🩺 產檢紀錄 | 每次產檢可記體重、血壓、胎心、醫師交代；體重自動進入孕期體重曲線 |
| 📒 孕期「紀錄」分頁 | 身體狀況、產檢、體重、胎動、宮縮在同一條時間軸，依孕週分組，產檢時直接給醫師看 |
| ⚠️ 警訊提醒 | 記錄到需要就醫的狀況立刻跳出：留意 →「請盡快聯絡醫師」、嚴重 →「請立即就醫」＋一鍵 119、心理危機 → 孕產婦關懷專線 0800-870-870／安心專線 1925。血壓 ≥140/90 提醒、≥160/110 立即就醫 |
| 🎉 生產紀錄 | 「寶寶出生了」填出生時間、體重、身長、頭圍、自然產／剖腹產、醫院，自動算出生週數；自動切換到育兒＋坐月子（二寶也適用） |
| 🍲 坐月子 | 首頁「坐月子・產後第 N 天」卡；產後恢復紀錄（惡露量與顏色、傷口疼痛 0–10、體溫、心情、17 種狀況）；最近變化圖；兩週內多天心情低落主動提供專線；產後 6 週後自動收起 |
| 👶 新生兒觀察（出生 28 天內） | 今天濕尿布 vs「第 N 天至少 N 片」、異常便色、體重變化（>10% 下降提醒）、黃疸與臍帶提醒 |
